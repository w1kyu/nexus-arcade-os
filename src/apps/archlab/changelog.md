# Changelog - Number & CPU Lab

## 1.0.0 (Phase 8)

- Integer formats: Unsigned, Sign-Magnitude, 1's Complement, and 2's Complement with 4–64 bit width support.
- Binary addition simulator with C, V, Z, S flag analysis.
- IEEE 754 Floating-Point Inspector for half, single, and double precisions.
- Step-by-step division and multiplication base conversion tables.
- Nexus-8 8-bit CPU simulator with fetch-decode-execute visualization.
- Assembly code editor with syntax parsing, memory map, and step runner.
