# AI Assistant

AI Assistant provides fast, lightweight writing and coding utilities directly accessible from any app in Nexus Arcade OS.

## Actions

- **Explain:** Clear, intuitive explanation of selected text, code, or math.
- **Summarize:** Concise bulleted summary and takeaways.
- **Translate:** Translate between German and English (or other languages).
- **Refactor / Optimize:** Improve code structure, readability, and performance.
- **Fix Grammar:** Grammar and spell checking with explanations.
