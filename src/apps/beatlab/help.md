# Beat Lab

Compose drum beats and rhythms with pure Web Audio synthesis.

## Features

- **100% Synthesized Drums:** 8 analog-style drum instruments (Kick, Snare, Closed Hi-Hat, Open Hi-Hat, Clap, Tom, Rimshot, Cowbell).
- **Rock-Solid Timing:** Jitter-free lookahead Web Audio scheduler.
- **Groove Controls:** Tempo slider (50–200 BPM) and adjustable swing.
- **Pattern Arrangements:** Create multiple patterns (A, B, C, D) and arrange song chains.
- **Lossless WAV Export:** Renders entire songs offline directly to 16-bit 44.1kHz WAV files in `/Music`.
- **Project Files:** Save and reopen `.nbeat` project files.
