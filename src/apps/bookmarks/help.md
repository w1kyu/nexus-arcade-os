# Bookmarks & Reading List

Organize favorite web links, collections, tags, reading list with read/unread tracking, and browser HTML import/export.

## Features

- **Collections & Tags**: Categorize web links into custom folders and tag them for fast filtering.
- **Reading List**: Save articles for later and mark items as read or unread.
- **Letter Avatar Fallback**: Privacy-first link representation using domain letter avatars without external network requests or tracking.
- **Browser HTML Import & Export**: Import your existing bookmarks from Firefox, Chrome, Safari, or Edge, and export them as standard Netscape Bookmark HTML.
- **One-Click Navigation**: Open bookmarks directly in a new browser tab.
