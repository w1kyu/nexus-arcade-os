# Breakout Nexus

Advanced continuous collision physics breakout game with power-up cascades, handcrafted levels, and integrated level editor.

## Features

- **Continuous Collision Physics**: Sub-stepped trajectory calculation prevents ball tunneling through paddle or bricks.
- **Angle Deflection**: Strike balls off paddle edges to produce sharp angles.
- **Power-Ups**: Multi-ball, Laser blaster, Sticky paddle, Slow ball, Extra life, Fireball.
- **Level Editor**: Design custom brick fields and save them directly to the Virtual File System (VFS).
