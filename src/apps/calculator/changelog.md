# Changelog — Calculator

## 1.0.0

- Standard & Scientific calculator modes with recursive-descent expression parser.
- Programmer mode with 8/16/32/64-bit word size and 64-bit interactive bit grid.
- Graphing mode plotting arbitrary functions with numerical root detection.
- 2x2 linear system and quadratic equation solvers.
- Statistics mode with mean, median, variance, and standard deviation.
- Terminal integration (`calc <expression>`).
