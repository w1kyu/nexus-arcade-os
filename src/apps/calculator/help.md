# Calculator

Multi-mode calculator featuring Standard, Scientific, Programmer, Graphing, Equation Solvers, and Statistics.

## Features

- **Standard & Scientific Modes**: Arithmetic, parentheses, percentages, trigonometry (deg/rad), powers, roots, logarithms, factorials, and mathematical constants ($\pi$, $e$).
- **Programmer Mode**: Real-time conversions across Hexadecimal, Decimal, Octal, and Binary, with 8/16/32/64-bit word sizes, bitwise logic (AND, OR, XOR, NOT, shifts), and an interactive 64-bit clickable grid.
- **Graphing Mode**: Function plotting $y = f(x)$ on an interactive canvas with automatic numerical root finding via bisection.
- **Equation Solvers**: Direct solutions for 2x2 linear systems and quadratic equations $ax^2 + bx + c = 0$.
- **Statistics Mode**: Instant calculation of Mean, Median, Variance, Standard Deviation, Sum, and Count for arbitrary number sets.
