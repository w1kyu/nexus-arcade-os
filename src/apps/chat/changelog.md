# Changelog — AI Chat

## 1.0.0 (Phase 12)

- Initial release of AI Chat for Nexus Arcade OS.
- Universal provider abstraction (Ollama, Lemonade, OpenAI-compatible APIs, Anthropic).
- Encrypted key storage at rest.
- Streaming responses with stop, branch editing, and regeneration.
- Markdown, code highlighting, and KaTeX math rendering.
- Saved personas library and dynamic prompt templates.
- RAG knowledge with VFS notes indexing and citation badges.
- Confirmed OS tool calling for notes, tasks, and calendar events.
- Code assistant mode with code panel and diff view.
- Side-by-side model compare mode.
