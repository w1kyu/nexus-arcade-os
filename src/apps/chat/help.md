# AI Chat

AI Chat brings conversational AI to Nexus Arcade OS, powered entirely by the servers you configure (local or remote). Nexus never fakes AI responses.

## Key Features

- **Local & Cloud Models:** Connect to Ollama, Lemonade, LM Studio, vLLM, OpenRouter, OpenAI, or Anthropic.
- **Privacy & Security:** API keys are encrypted at rest with a device key and never sent to telemetry or logs.
- **Rich Message Rendering:** Complete Markdown rendering with syntax-highlighted code blocks, copy buttons, and LaTeX math via KaTeX.
- **Message Branching:** Edit any previous user message to branch the conversation and explore alternative paths.
- **Streaming & Controls:** Live streaming responses with a Stop button, regenerate, and side-by-side model compare mode.
- **Personas:** Switch between specialized assistants like CS Tutor, Code Reviewer, German ↔ English Translator, and Exam Coach.
- **Prompt Templates:** Insert parameterized templates (`{{topic}}`, `{{language}}`) with dynamic input forms.
- **Knowledge (RAG):** "Use my notes" toggle indexes your VFS Notes folder using vector embeddings to cite your notes.
- **OS Actions:** Models with tool-calling capabilities can propose creating notes, tasks, or calendar events with confirmation approval cards.
- **Code Assistant Mode:** Split-view code panel next to the chat with quick actions (Explain, Find bugs, Optimize, Write tests) and send to Code Playground.
