# Logic Circuit & Boolean Lab

Interactive digital electronics and Boolean algebra educational workbench.

## Features

- **Circuit Simulator**: Drag gates (AND, OR, NOT, NAND, NOR, XOR, XNOR, Buffer), inputs (switches, clock), outputs (LEDs, 7-segment display).
- **Signal Flow**: Real-time signal propagation and wire states with color coding.
- **Circuit Presets**: Half Adder, Full Adder, SR Latch, etc.
- **Truth Table Generator**: Exhaustive evaluation across all switch combinations.
- **Boolean Algebra Engine**: Parse formulas with standard notations (`A & B | !C`, `(A ∧ B) ∨ ¬C`, `AB + C'`).
- **Karnaugh Maps (KV Maps)**: 2, 3, and 4 variables with Gray-code coordinate mapping.
- **Quine-McCluskey Minimization**: Exact prime implicant identification yielding optimal DNF and CNF representations.
