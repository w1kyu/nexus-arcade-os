# Changelog — Clipboard

## 1.0.0

- Real-time history of copied text inside Nexus OS with origin app badges.
- Automatic privacy filter excluding sensitive items from Password Vault.
- Pinned clips collection preserving important snippets across history clears.
- Full-text search and filtering across clips and templates.
- Text snippets supporting `{{date}}`, `{{time}}`, `{{datetime}}`, and `{{clipboard}}` variable expansion.
- Command palette and terminal commands (`clipboard list`, `clipboard clear`, `clipboard copy`, `clipboard snippet`).
