# Clock

World clock, multiple named countdown timers, stopwatch with lap recording, and cross-timezone meeting planner.

## Features

- **World Clock**: Shows analog and digital clocks across major international time zones formatted with native `Intl` APIs.
- **Multiple Named Timers**: Create and monitor independent countdown timers (e.g. Pomodoro, tea, cooking).
- **Stopwatch**: High-precision stopwatch with lap split recording and one-click text/CSV export.
- **Meeting Planner**: Visual 24-hour overlap matrix highlighting the optimal meeting windows that fall inside standard working hours across multiple global cities.
