# Changelog

## 1.0.0

- Initial release of Nexus Code.
- Project folder file tree with file/folder creation, rename, and deletion.
- CodeMirror 6 editor with syntax highlighting, autocomplete, and bracket matching.
- Live web preview using blob URLs for local asset resolution.
- Node-Lite worker runner for quick script execution.
- Local history snapshots with integrated diff viewer.
- Global search across files and Quick Open (`Mod+P`).
