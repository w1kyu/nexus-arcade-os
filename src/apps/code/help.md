# Nexus Code

**Nexus Code** is a multi-file workspace and code editor tailored for web development and scripting inside Nexus Arcade OS.

## Key Features

- **Project Explorer**: Navigate files and folders within any VFS folder (default: `~/Projects`).
- **Full Editor Features**: Powered by CodeMirror 6 with syntax highlighting for HTML, CSS, JavaScript, JSON, Markdown, and more.
- **Search Across Files**: Fast recursive search with match case, whole word, and regular expressions.
- **Quick Open (`Mod+P`)**: Jump to any file by typing part of its name.
- **Go to Line (`Mod+G`)**: Direct line jumping.
- **Split Editors**: View files side by side or stacked.
- **Live Web Preview**: Runs `index.html` inside a sandboxed iframe with project assets mapped via secure blob URLs.
- **Node-Lite (JavaScript Runner)**: Run `.js` files safely in an isolated Web Worker with console capture.
- **Local History & Diff**: Automatic snapshots when files are saved, with side-by-side or inline diff viewing.

## Keyboard Shortcuts

- `Mod+S`: Save active file
- `Mod+P`: Quick Open file
- `Mod+G`: Go to line
- `Mod+F`: Find and Replace
