# Color Laboratory Help

The Color Laboratory provides professional color manipulation, palette creation, contrast verification, and gradient design tools.

## Features

- **Color Converter:** Convert seamlessly between HEX, RGB(A), HSL(A), HSV, CMYK, OKLCH, and standard CSS named colors.
- **Palette Generator:** Create harmonic palettes (Complementary, Analogous, Triadic, Tetradic, Monochromatic, Shades/Tints). Lock favorite colors and regenerate the rest. Export as CSS variables, JSON, or SCSS.
- **Contrast Checker:** Verify accessibility compliance with WCAG 2.x AA and AAA standards for normal and large text, as well as APCA perceptual scores.
- **OS Integration:** Set any selected color directly as the active Nexus OS accent color.
- **Color Blindness Simulator:** Preview individual colors and palettes through Protanopia, Deuteranopia, Tritanopia, and Achromatopsia filters.
- **Gradient Builder:** Design Linear, Radial, and Conic gradients with live interactive previews and CSS export.
- **Extract from Image:** Pick any image from VFS or upload from device to automatically extract dominant color palettes using k-means clustering.
