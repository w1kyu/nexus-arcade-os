# Unit Converter

Two-way live conversion across 16 categories, SI vs IEC data size distinctions, number bases, and Roman numerals.

## Features

- **16 Categories**: Length, Data Size (SI vs IEC: kB vs KiB), Temperature, Mass, Speed, Area, Volume, Time, Pressure, Energy, Power, Angle, Data Rate, Frequency, Fuel Economy, and Cooking units.
- **SI vs IEC Data Sizes**: Exact conversions distinguishing between decimal SI ($1\text{ kB} = 1000\text{ B}$) and binary IEC ($1\text{ KiB} = 1024\text{ B}$).
- **Two-Way Live Conversion**: Edit either the left or right input for instantaneous recalculation.
- **Number Bases**: Live synchronized conversion across Binary (2), Octal (8), Decimal (10), and Hexadecimal (16).
- **Roman Numerals**: Convert between standard Arabic numerals and Roman numerals ($1$ to $3999$).
- **Terminal Integration**: Fast shell conversions via `convert <value> <from> to <to>` (e.g. `convert 100 km to mi`).
