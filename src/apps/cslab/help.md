# CS Lab Hub

The central educational hub and syllabus guide for university-level Computer Science (_Informatik_).

## Integrated Tools

1. **Sorting Visualizer** (`nexus.sorting`): 10 sorting algorithms, comparison audio, race mode, and complexity analysis.
2. **Pathfinding & Maze Lab** (`nexus.pathfinding`): BFS, DFS, Dijkstra, A*, Greedy Best-First, Bidirectional BFS, and 5 maze generators.
3. **Graph Editor & Algorithms** (`nexus.graphlab`): Force-directed layouts, 12 graph algorithms with step execution, DOT/matrix export.
4. **Data Structures Visualizer** (`nexus.datastructures`): 11 core data structures including AVL tree rotations, heaps, hash tables, and tries.
5. **Automata Lab** (`nexus.automata`): DFA/NFA simulator, NFA to DFA subset construction, DFA minimization, Thompson regex conversion.
6. **Turing Machine Simulator** (`nexus.turing`): Single-tape execution with animated head, state table, and busy beaver presets.
7. **Logic Circuit Simulator** (`nexus.circuits`): Real-time digital logic gate wiring, truth tables, KV maps, and Quine-McCluskey minimization.
8. **Number & CPU Lab** (`nexus.archlab`): IEEE 754 floating point inspector, two's complement arithmetic flags, and Nexus-8 toy CPU simulator.
