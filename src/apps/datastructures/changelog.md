# Changelog

## 1.0.0

- Initial release of Data Structures Visualizer for Phase 8.
- 11 data structures: Dynamic Array, Stack, Queue, Circular Buffer, Singly/Doubly Linked Lists, BST, AVL Tree, Binary Heap, Hash Table, and Trie.
- Interactive buttons and command line input.
- Step-by-step generator animations and explanations.
- SVG and PNG export, VFS state save/load.
