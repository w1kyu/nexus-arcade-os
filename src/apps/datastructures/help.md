# Data Structures Visualizer

Interactive visualization and step-by-step animation of core data structures in computer science.

## Covered Data Structures

- **Array / Dynamic Array**: Resizing, shifting, and random access.
- **Stack (LIFO)**: Push, pop, and top inspection.
- **Queue (FIFO)**: Enqueue, dequeue, and front inspection.
- **Circular Buffer**: Fixed-size ring buffer with modulo pointer arithmetic.
- **Singly & Doubly Linked Lists**: Dynamic node linking with pointers.
- **Binary Search Tree (BST)**: Binary search insertion, deletion, and search.
- **AVL Tree**: Self-balancing BST with LL, RR, LR, and RL rotations.
- **Binary Heap**: Array and tree view with bubble-up and sink-down operations.
- **Hash Table**: Separate chaining and open addressing (linear / quadratic probing).
- **Trie (Prefix Tree)**: Character branching for string search and autocomplete prefixes.

## Interactive Mini-CLI

Execute commands directly in the command bar:
`insert 42`, `delete 10`, `search 7`, `push 15`, `pop`, `enqueue 9`, `dequeue`.
