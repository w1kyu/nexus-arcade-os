# Developer Tools Help

Nexus Developer Tools is a comprehensive developer toolbox that stays fast and works completely offline.

## Included Tools

- **JSON Toolkit:** Format (2/4 spaces, tabs), minify, sort keys, validate with exact syntax error line and position, convert to CSV/YAML/TypeScript/JSDoc, query with JSONPath, and validate against JSON Schemas.
- **Encoding & Crypto:** Base64/Base32, Hex, Binary, URL, HTML Entities, Unicode escapes, Punycode, Hashes (MD5, SHA-1, SHA-256, SHA-384, SHA-512, CRC32), HMAC signatures, AES-GCM password encryption, and RSA/ECDSA keypair generator.
- **Regex Tester:** Test regex with live match highlighting, group capture table, replace mode with backreferences ($1, $<name>), pattern library, cheat sheet, and catastrophic backtracking protection.
- **JWT Debugger:** Decode headers and payloads, check token expiry dates, and verify HS256 signatures with secret keys.
- **UUID / ULID / NanoID Generator:** Bulk generation for UUID v4, timestamp-ordered UUID v7, ULID, and NanoID.
- **Timestamp Converter:** Convert Unix seconds, milliseconds, ISO 8601 strings, and relative human times.
- **Number Base Converter:** Convert between bases 2 through 36, view 8/16/32-bit two's complement and big/little endian bytes.
- **Cron Expression Tool:** Explain expressions in plain English and German and compute the next 10 scheduled occurrences.
- **Text Tools:** Case conversions (camelCase, snake_case, kebab-case, PascalCase, CONSTANT_CASE, Title Case), slugify, sort lines, dedupe, stats, and lorem ipsum generator.
- **Markdown Table Generator:** Visual editable spreadsheet grid that generates Markdown, HTML, and CSV tables.
- **CSS Generators:** Interactive visual generators for box-shadow, border-radius, clip-path, cubic-bezier timing curves, and flexbox/grid playgrounds.
- **SVG Optimizer:** Clean SVG markup, strip comments and metadata, preview and export to PNG or Data URI.
- **QR Code Generator:** Generate high-resolution SVG/Canvas QR codes from any text or URL.
- **Fake Data Generator:** Generate realistic sample users (names, emails, addresses, numbers in English or German).
- **Dev Cheatsheets:** Interactive reference for HTTP status codes, MIME types, and keyboard event keys.
