# Diff Viewer Help

The Diff Viewer compares two versions of text or two files from the VFS.

## Features

- **Side-by-side and Inline views:** Toggle between split columns and unified line-by-line view.
- **Word-level highlighting:** Modified lines highlight the exact characters and words that changed.
- **Options:** Ignore whitespace differences and ignore letter casing.
- **Navigation:** Use the previous / next change buttons to jump directly between changed hunks.
- **Export Patch:** Export changes as standard unified diff `.patch` files.
- **VFS Integration:** Open files directly from the Nexus Virtual File System.
