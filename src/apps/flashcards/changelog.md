# Changelog — Flashcards

## 1.0.0

- Decks and nested subdecks (`Parent::Child`).
- Markdown, KaTeX MathML, and syntax-highlighted code cards.
- Basic, reversed, cloze deletion, and type-the-answer card types.
- Free Spaced Repetition Scheduler (FSRS) implementation.
- Keyboard-driven study sessions with undo and flip animation.
- Anki `.apkg` package and CSV/TSV import/export.
