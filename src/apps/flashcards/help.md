# Flashcards

Decks and subdecks, Markdown and KaTeX math formulas, cloze deletion, FSRS spaced repetition, and Anki `.apkg` package import.

## Features

- **Decks & Hierarchies**: Organize study material with decks and subdecks (e.g. `Computer Science::Operating Systems`).
- **Markdown & Math**: Full support for rich text, code highlighting, and LaTeX math via KaTeX MathML.
- **Card Types**: Standard cards, reversed pairs, cloze deletions (`{{c1::answer}}`), and typed-answer cards.
- **FSRS Spaced Repetition**: Modern Free Spaced Repetition Scheduler computing card stability and interval forecasts.
- **Keyboard-Only Review**: Use Space to flip and keys `1`–`4` for Again, Hard, Good, and Easy ratings.
- **Anki Import**: Import decks directly from `.apkg` files using bundled `fflate` and `sql.js`.
