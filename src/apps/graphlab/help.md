# Graph Editor & Algorithms

An interactive canvas for creating, laying out, and analyzing directed and undirected graphs.

## Features

- **Visual Graph Drawing**: Add, move, delete nodes and edges with customizable weights.
- **Auto-Layouts**: Force-directed simulation, circular placement, and grid arrangement.
- **Graph Algorithms**:
  - BFS & DFS (with discovery and finish times)
  - Dijkstra's Algorithm (shortest path)
  - Bellman-Ford (with negative cycle detection)
  - Floyd-Warshall (all-pairs distance matrix)
  - Prim's & Kruskal's Minimum Spanning Tree (MST)
  - Topological Sort (Kahn's in-degree)
  - Tarjan's Strongly Connected Components (SCC)
  - Bipartite Check (2-coloring)
  - Cycle Detection
  - Edmonds-Karp Max Flow
- **Import / Export**: Graphviz DOT, Adjacency Matrix, and Adjacency List formats.
