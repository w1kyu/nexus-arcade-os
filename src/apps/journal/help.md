# Journal

Daily personal journal with mood tracking, VFS photos, "On this day" reflections, writing prompts, and AES-GCM password encryption.

## Features

- **Daily Markdown Entries**: Write rich daily notes with Markdown formatting, headings, checklists, and code.
- **5-Point Mood Scale**: Track how you feel each day with expressive icons (Awful, Down, Neutral, Good, Great).
- **On This Day**: Relive entries written on the same day in previous years.
- **Writing Prompts**: In-app bilingual (EN/DE) writing prompts to inspire daily reflection.
- **Word Count & Stats**: Live word count and 30-day mood analytics timeline.
- **AES-GCM Password Encryption**: Optional full journal encryption using Web Crypto PBKDF2-SHA256 and AES-GCM with instant auto-lock.
