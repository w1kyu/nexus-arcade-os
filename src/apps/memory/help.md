# Memory Master

Train working memory and recognition speed by flipping cards to match pairs.

## Scoring & Combos

- **Matches**: Each match awards 100 points multiplied by your active combo streak.
- **Combo Chains**: Find pairs consecutively without making a mistake to climb x2, x3, x4 multipliers!
- **Star Ratings**: Complete the grid with low moves and high speed to earn up to 3 stars.

## Themes

- **OS Icons**: Tech and desktop icons.
- **Cyber Neon**: Vibrant glowing color swatches.
- **CS Terms**: Core data structures, algorithms, and system concepts.
- **Math Constants**: Mathematical and computational figures.
