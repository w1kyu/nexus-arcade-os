# Changelog - Nexus Mind Map

## 1.0.0 - 2026-11-10

- Initial release of Nexus Mind Map for Phase 6.
- Keyboard-first interaction: Tab (child), Enter (sibling), Delete, Space (collapse).
- Multiple auto-layout engines: Right Tree, Radial Tree, and Org Chart.
- Dynamic Bezier connection curves and capsule node styling.
- Node coloring and branch folding.
- Markdown outline bidirectional import and export.
- SVG and PNG export capabilities.
- Branch to tasks checklist extraction.
- Native `.nmap` JSON persistence in VFS.
