# Nexus Mind Map

Nexus Mind Map is a fast, keyboard-first tool for mapping thoughts, brainstorming projects, and organizing complex topics visually.

## Keyboard Shortcuts

- **Add Subtopic (`Tab`):** Create a new child branch under the selected topic.
- **Add Sibling (`Enter`):** Create a new parallel topic at the same level.
- **Delete (`Delete` / `Backspace`):** Remove the selected topic and its subtopics.
- **Fold / Unfold (`Space`):** Collapse or expand child branches of the selected topic.
- **Navigate (`Arrows`):** Move selection across parent, children, and siblings.
- **Edit Text:** Double-click any node to rename it.

## Auto-Layout Modes

- **Right Tree:** Traditional horizontal left-to-right expansion.
- **Radial Tree:** Circular radiating branches centered on the main topic.
- **Org Chart:** Top-down vertical hierarchy for organizational diagrams.

## Data Exchange

- **Markdown:** Import existing Markdown outlines or export your mind map to a clean Markdown bullet list.
- **Graphics:** Export high-resolution PNG or vector SVG graphics.
- **Tasks:** Extract all subtopics in a branch into a Markdown checklist for Nexus Tasks.
