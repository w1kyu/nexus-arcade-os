# Changelog - Nexus Paint

## 1.0.0 - 2026-11-10

- Initial release of Nexus Paint for Phase 6.
- Multi-layer canvas with visibility, opacity, reordering, duplicate and merge down.
- Comprehensive brushes: Round, Soft Airbrush, Pencil, Spray Can, Eraser.
- 4-way flood fill bucket with color tolerance.
- Real-time horizontal symmetry drawing.
- Full image adjustments: Brightness/Contrast, Hue/Saturation, Invert, Grayscale, Blur.
- Multi-format exporter: PNG, JPEG, WebP and layered `.npaint` JSON.
