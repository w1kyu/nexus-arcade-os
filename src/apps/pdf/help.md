# PDF Tools

PDF Tools is a lightweight document scanner and PDF viewer for Nexus Arcade OS.

## Features

- **Document Viewer:** View any standard PDF file with native browser controls (pan, zoom, multi-page scroll, search).
- **Image-to-PDF Combiner:**
  - Import scanned receipts, documents, or photos (PNG, JPEG, WebP).
  - Reorder pages with one click.
  - Rotate pages in 90° increments to fix scanned orientations.
  - Page formats: A4, US Letter, or Fit Image.
  - Orientation: Portrait or Landscape.
- **Pure JavaScript PDF Generation:** Generates valid standard PDF 1.4 documents offline with zero server dependencies.
- **Save & Print:** Save directly into the sandboxed Virtual File System or send to a local printer.
