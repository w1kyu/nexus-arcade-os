# Nexus Photos

Browse, inspect, and edit your local picture library offline.

## Features

- **EXIF Inspector:** View real JPEG camera metadata, exposure time, aperture, ISO, and GPS coordinates.
- **Lightbox Viewer:** Smooth pan & zoom, 1:1 view toggle, and full-screen slideshow with transition intervals.
- **Photo Editor:** Rotate 90°, flip, crop, resize, adjust brightness/contrast/saturation/warmth, and apply creative filters.
- **Privacy Tools:** Redact sensitive information with the privacy pixelation brush, or strip EXIF metadata entirely on export.
- **System Integration:** Set any photo as desktop wallpaper or profile avatar.
