# Changelog

## 1.0.0 — Initial Release

- Grid canvas with 8x8 to 128x128 dimensions.
- Pencil, eraser, bucket fill, line, rectangle, circle, and eyedropper tools.
- Retro palettes: PICO-8, Game Boy, Commodore 64, NES Classic, and custom swatches.
- Onion skinning and horizontal mirror drawing mode.
- Frame timeline with play/pause animation preview and FPS control.
- Scaled PNG, sprite sheet, and animated GIF89a export.
