# Code Playground Help

The Code Playground gives you an isolated sandbox to experiment with web technologies in real time.

## Features

- **Editors:** Edit HTML, CSS, and JavaScript in dedicated panels with line numbering, bracket matching, and auto-indent.
- **Sandboxed Live Preview:** Code runs in an isolated `iframe` with `sandbox="allow-scripts"` (no same-origin access), protecting the OS kernel.
- **Console Panel:** Captures `console.log`, `console.warn`, `console.error`, and `console.table` outputs and uncaught script errors.
- **REPL Input:** Type JavaScript expressions in the console prompt to execute them live in the preview context.
- **Layouts:** Switch between Side-by-Side, Stacked, Preview-Only, and Editor-Only view modes.
- **Templates:** Start from Canvas game loops, 3D CSS animations, Fetch demos, or Web Components.
- **Export & Import:** Export as a single self-contained HTML file or import existing HTML pages.
