# Changelog

## 1.0.0 — Initial Release

- Markdown-driven slide authoring using `---` dividers.
- Built-in math rendering via KaTeX and syntax-highlighted code blocks.
- Themes: Nexus Dark, Clean Light, Terminal Retro, Cyberpunk Neon, and Warm Paper.
- 16:9 and 4:3 aspect ratios.
- Fullscreen slide show presentation mode.
- Presenter mode with elapsed stopwatch timer, dual-slide preview, and speaker notes.
- Standalone offline HTML export and print-to-PDF styles.
