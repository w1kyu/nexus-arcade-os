# Quiz Arena

Challenge your knowledge in Computer Science, software engineering, logic puzzles, and general trivia!

## Game Mechanics

- **Timer:** You have 15 seconds to answer each question. Answering faster earns bonus speed points!
- **Streak Multipliers:** Consecutive correct answers award increasing multipliers (up to 3.0x)!
- **50:50 Lifeline:** Eliminate two incorrect options once per game session.
- **Detailed Explanations:** Every question provides an educational explanation for why the answer is correct.
- **Custom Quiz Packs:** Import your own JSON trivia packs anytime!
