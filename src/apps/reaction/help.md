# Reaction Trainer

Benchmark and train fundamental sensory processing speed, eye-hand coordination, and cognitive capacity.

## Tests

1. **Reaction Time**: Wait for red to change to green, then click. Detects false starts.
2. **Aim Trainer**: Click 30 rapidly appearing circular targets.
3. **Sequence Memory**: Simon Says sequence memory test with expanding sound and visual steps.
4. **Number Memory**: Remember increasingly long numbers shown for a limited duration.
5. **Visual Memory**: Recall positions of flashed squares in an expanding grid.
6. **Choice Reaction**: Reaction time test incorporating decision latency (Hick's Law).
