# Voice Recorder

Record voice memos, interviews, and lectures with live waveform feedback.

## Features

- **Live Waveform:** Visualizes sound waves in real-time via Web Audio.
- **Bookmarks:** Add timestamped markers while recording.
- **Variable Playback Speed:** Listen at 0.5× up to 2× speed.
- **Audio Trimming:** Specify start and end markers to trim sections.
- **VFS Storage:** All audio recordings are stored in `/Music/Recordings`.
