# Changelog - Pixel Runner

## [1.0.0] - 2026-11-11

- Initial release for Nexus Arcade OS Phase 10 Tier 3.
- 20 handcrafted levels with ascending challenge and variety.
- Responsive physics: coyote time (120ms), jump buffering (120ms), and variable jump height.
- In-game Level Editor with full tile palette, instant playtesting, and JSON import/export.
