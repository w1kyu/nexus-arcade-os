# Pixel Runner

Pixel Runner is an agile neon 2D platformer with responsive momentum physics, jump buffering, and coyote time.

## Controls

- **Move Left / Right:** Left / Right Arrow or A / D keys (or Gamepad D-pad / Left stick)
- **Jump:** Up Arrow, W, or Space (or Gamepad A / Cross button). Releasing early cuts jump height!
- **Respawn / Restart:** R key

## Interactive Mechanics

- **Springs (Bouncers):** Jump on orange springs for a high-velocity vertical boost.
- **Crumbling Blocks:** Disintegrate shortly after you step on them.
- **One-way Platforms:** Jump through from underneath.
- **Keys & Doors:** Find gold keys to unlock matching barriers blocking portals.
- **Level Editor:** Click "Level Editor" in the top bar to paint custom layouts, place hazards, test play instantly, and export/import level JSON files!
