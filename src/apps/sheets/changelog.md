# Changelog - Nexus Sheets

## 1.0.0 - 2026-11-10

- Initial release of Nexus Sheets for Phase 6.
- Virtual scrolling grid supporting up to 10,000 rows.
- Complete custom formula engine with DAG dependency calculation and cycle detection.
- 40+ spreadsheet functions (SUM, AVERAGE, MIN, MAX, IF, IFS, VLOOKUP, XLOOKUP, INDEX, MATCH, etc.).
- Multi-sheet tabs, formatting options, and sorting.
- Canvas-based chart generation (Bar, Line, Pie, Scatter).
- TSV clipboard copy/paste and CSV export.
