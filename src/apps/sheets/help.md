# Nexus Sheets

Nexus Sheets is a full-featured, offline spreadsheet application built for Nexus Arcade OS. It provides virtual scrolling, custom formula calculations, chart generation, and data import/export.

## Features

- **Formula Engine:** 40+ built-in functions covering Math, Statistics, Logic, Text, Date, and Lookups.
  - Math & Stats: `SUM`, `AVERAGE`, `MIN`, `MAX`, `ROUND`, `ABS`, `SQRT`, `POWER`, `MOD`, `STDEV`, `MEDIAN`, `RAND`, `RANDBETWEEN`
  - Counting & Conditions: `COUNT`, `COUNTA`, `COUNTIF`, `SUMIF`, `AVERAGEIF`, `IF`, `IFS`, `AND`, `OR`, `NOT`
  - Text: `CONCAT`, `LEFT`, `RIGHT`, `MID`, `LEN`, `UPPER`, `LOWER`, `TRIM`
  - Date & Time: `TODAY`, `NOW`, `DATE`, `YEAR`, `MONTH`, `DAY`
  - Lookup: `VLOOKUP`, `XLOOKUP`, `INDEX`, `MATCH`
- **Virtual Scrolling:** Seamless grid navigation handling up to 10,000 rows and 100 columns.
- **Embedded Charts:** Visualize data instantly with Bar, Line, Pie, and Scatter plots rendered via HTML5 Canvas.
- **Data Exchange:** Copy and paste tab-separated values (TSV) to and from external spreadsheets, and export clean CSV files.
- **Undo / Redo:** Full history tracking up to 100 actions.
