# Snippet Manager Help

Snippet Manager helps you save, organize, and reuse reusable pieces of code and configuration across projects.

## Features

- **Organization:** Categorize snippets with titles, descriptions, programming languages, tags, and custom folders.
- **Instant Search:** Filter snippets quickly by name, code text, or tag.
- **1-Click Copy:** Copy snippet code immediately to your clipboard.
- **IDE Intents:** Insert snippets directly into Code Playground or Nexus Code.
- **Import & Export:** Backup and restore your snippet library as JSON files.
