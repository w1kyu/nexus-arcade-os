# Changelog

## 1.0.0 (2026-11-11)

- Initial release of Block Pusher (Sokoban).
- 64 verified solvable puzzle levels of escalating difficulty.
- Step and push counters with infinite undo history.
- Integrated level editor with XSB import/export and BFS solvability solver.
- Gamepad and keyboard arrow / WASD movement abstraction.
