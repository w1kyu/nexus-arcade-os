# Block Pusher (Sokoban)

Block Pusher is a classic Japanese warehouse puzzle game where you push crates onto designated storage locations.

## Rules & Controls

- Move with Arrow Keys, WASD, or D-Pad / Thumbstick on Gamepad.
- Push boxes onto target goal markers (`.`).
- You can only push one crate at a time; you cannot pull boxes.
- Avoid pushing boxes into dead corners where they cannot be extracted.
- Infinite Undo lets you reverse any accidental pushes.

## Level Editor

- Switch between Play mode and Level Editor.
- Draw walls, floor tiles, boxes, targets, or the player.
- Click "Test Solvability" to run the automated BFS solver to prove your level can be solved.
- Export and import standard XSB level files.
