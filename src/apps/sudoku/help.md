# Sudoku

A logic-based, combinatorial number-placement puzzle.

## Goal

Fill the 9×9 grid with digits 1 through 9 such that each column, each row, and each of the nine 3×3 subgrids (boxes) contains all of the digits from 1 to 9.

## Features

- **Pencil Marks:** Switch to Notes mode (✏️ or key `N`) to jot candidate numbers inside empty cells.
- **Auto Notes:** Click ⚡ Auto Notes to automatically calculate and populate all remaining valid candidate numbers.
- **Technique Hints:** Click 💡 Hint to receive an explanation of advanced deduction techniques (such as Naked Singles or Hidden Singles in rows, columns, or boxes).
- **Daily Puzzle:** Every day features a synchronized puzzle challenge for all players.
