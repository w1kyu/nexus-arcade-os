# Synthesizer Changelog

## 1.0.0

- Initial release of Nexus Synthesizer for Phase 11.
- Polyphonic dual-oscillator sound engine with lowpass filtering and ADSR envelopes.
- Built-in multi-mode Arpeggiator and effects rack (Delay, Reverb, Distortion).
- Interactive 3-octave on-screen piano keyboard and QWERTY keyboard mapping.
- Real-time oscilloscope and frequency spectrum visualizer.
- Web MIDI API integration and VFS preset saving/loading.
