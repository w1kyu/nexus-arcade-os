# Synthesizer Help

Nexus Synthesizer is a polyphonic analog-style software synthesizer designed for sound design, live performance, and offline music creation.

## Features

- **Dual Oscillators:** Select Sawtooth, Square, Sine, Triangle, or Noise for both Oscillator 1 and Oscillator 2. Tune octaves, semitones, and cents fine detune.
- **Resonant Filter:** Multimode filter with Cutoff and Resonance (Q), modulated by a dedicated Filter ADSR envelope and LFO.
- **Envelopes:** Independent 4-stage ADSR (Attack, Decay, Sustain, Release) envelopes for Amplitude and Filter cutoff modulation.
- **LFO:** Low Frequency Oscillator routed to either Filter Cutoff or Pitch vibrato.
- **Effects Rack:** Built-in Delay (time/feedback), algorithmic Reverb (impulse response), and Waveshaping Distortion.
- **Arpeggiator:** Up, Down, Up/Down, and Random arpeggios synced to BPM across 1 to 3 octaves.
- **Controls & Input:**
  - **On-Screen Keyboard:** 3-octave interactive keyboard with mouse and touch support.
  - **Computer Keyboard:** Play keys using `A`, `W`, `S`, `E`, `D`, `F`, `T`, `G`, `Y`, `H`, `U`, `J`, `K`.
  - **Web MIDI:** Plug in any USB/Bluetooth MIDI keyboard or controller for hardware input.
- **Oscilloscope & Spectrum:** Real-time dual waveform visualizer powered by Web Audio AnalyserNode.
- **Presets & Export:** Load and save `.nsynth` patch files directly to the VFS.
