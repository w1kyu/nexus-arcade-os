# Changelog — Timetable

## 1.0.0

- Weekly university course grid with configurable hours and colors.
- Biweekly A/B weeks scheduling and semester period management.
- Live "Now & Next" status bar and desktop widget.
- Real-time overlay sync to Calendar via `~/.config/timetable-snapshot.json`.
- Direct cross-app links to Notes, Tasks, and Flashcards.
- RFC 5545 `.ics` and JSON import/export.
