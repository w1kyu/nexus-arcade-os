# Typing Trainer

Boost typing speed, accuracy, and muscle memory.

## Features

- **Real-Time Analytics:** Real-time calculation of WPM (standardized 5 chars/word), Raw WPM, Accuracy %, and Consistency %.
- **Touch Typing Finger Guides:** On-screen virtual keyboard with colored key highlights corresponding to correct anatomical finger placement (Left Pinky to Right Pinky).
- **Practice Modes:**
  - **Common Words:** Top high-frequency words for steady cadence.
  - **Quotes:** Curated famous engineering and computer science quotes.
  - **Code Typing:** Real-world code snippets in JavaScript, Python, Java, and C.
  - **German Text:** Practice typing umlauts (`ä`, `ö`, `ü`, `ß`) cleanly.
- **Error Heatmap:** Inspect the virtual keyboard heatmap to identify which keys cause the most typos.
