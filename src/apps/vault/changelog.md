# Changelog — Password Vault

## 1.0.0

- Master-password protected credential vault with AES-GCM encryption.
- Password and German/English passphrase generator with entropy estimation.
- 30-second clipboard auto-clear for sensitive copied credentials.
- RFC 6238 TOTP 2FA authenticator with dynamic truncation.
- Fully local password health check for reused, weak, and old passwords.
- Terminal integration (`vault`).
