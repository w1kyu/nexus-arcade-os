# Welcome

Welcome to **Nexus Arcade OS** — your offline-first browser desktop.

## Quick Highlights

- **Interactive First-Run Tour**: Launch the 5-step guided tour directly from Welcome or the Command Palette (`>Start interactive tour`).
- **Window Management**: Snap windows with drag-to-edge or `Ctrl+←↑→↓` (`⌘←↑→↓`), switch workspaces with `Ctrl+Shift+←→`, and view all open windows with `Ctrl+Shift+Space`.
- **Command Palette (`Ctrl+K`)**: Search apps, run commands (`>`), tweak settings (`@`), or convert units seamlessly.
- **Try Demo Profile**: Load a sample workspace pre-filled with notes, spreadsheets, tasks, and code files (marked **Demo** and removable at any time).
- **Backup & Restore**: Protect everything locally using encrypted `.nexus-backup` archives in **Settings → Backup & Restore**.
