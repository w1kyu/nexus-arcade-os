# Changelog - Nexus Whiteboard

## 1.0.0 - 2026-11-10

- Initial release of Nexus Whiteboard for Phase 6.
- Infinite canvas with smooth pan, zoom and centering controls.
- Full toolset: Select/Move, Pen with pressure support, Highlighter, Eraser.
- Vector shapes: Rectangle, Ellipse, Line, Arrow connector, Text, Sticky Notes, Frames.
- Interactive double-click editing for sticky notes and text blocks.
- Pre-built board templates: Flowchart, Kanban, SWOT Analysis.
- SVG and PNG image exporters.
- Native `.nboard` JSON file persistence in VFS.
