# Changelog - Nexus Write

## 1.0.0 - 2026-11-10

- Initial release of Nexus Write for Phase 6.
- WYSIWYG document editor with physical page view (A4 and Letter) and margins.
- Rich formatting: headings, bold, italic, underline, strike, colors, highlights, alignments.
- Complex blocks: blockquotes, code blocks, checklists, tables, images, horizontal rules.
- Real-time document outline with click-to-scroll navigation.
- Table of Contents generation.
- Full document statistics (word count, characters, reading time).
- Professional templates: DIN 5008 Business Letter, Curriculum Vitae, Formal Report, Lab Report.
- Multi-format import and export: `.ndoc` (JSON), Markdown (`.md`), HTML (`.html`), and plain text (`.txt`).
- Print stylesheet for clean "Print -> Save as PDF" output.
