# Nexus Write

Nexus Write is a professional, distraction-free document processor designed for Nexus Arcade OS. It combines visual page layout with rich text editing, document outlining, templates, and clean print export.

## Features

- **Rich Text Typography:** Headings (H1–H3), bold, italic, underline, strikethrough, text color, and highlight markers.
- **Block Elements:** Blockquotes, syntax-styled code blocks, interactive checklists with clickable checkboxes, bullet and numbered lists, and horizontal dividers.
- **Document Outline:** Real-time hierarchy tree showing document sections for rapid navigation.
- **Page Layout & Views:** Physical paper views (A4 and Letter) in portrait and landscape with customizable margins (Normal, Narrow, Wide).
- **Templates:** Instant templates for business correspondence (DIN 5008), curriculum vitae (CV), executive reports, and scientific lab reports.
- **Tables & Media:** Configurable data tables, inline images, and hyperlinks.
- **Table of Contents:** Auto-generated TOC block with jump links based on document headings.
- **Document Statistics:** Real-time word count, character count, and estimated reading time.
- **Open File Formats:** Saves natively as `.ndoc` JSON in the VFS; exports and imports Markdown (`.md`), HTML (`.html`), and plain text (`.txt`).
- **Print & PDF:** Professional `@media print` styling for clean, borderless PDF export via browser printing.
